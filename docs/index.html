Python is a general-purpose programming language known for readable code and a welcoming learning curve. You can use it for automation, websites, data, science, and plenty more. Read each example from top to bottom; change a value and see what happens.

01 — First steps

Say hello to Python

Python runs instructions in order. The print() function displays a value. Text goes inside quotes, and parentheses hold the function's input.

hello.py
print("Hello, world!")
print("I'm learning Python.")
Hello, world!
I'm learning Python.

Try Python in an online editor or install it from python.org. Save a file with a .py ending, then run it with python hello.py.

Small detail, big help: Python uses indentation to group code. Four spaces is the usual convention.

02 — Store a value

Give information a name

A variable is a name for a value. Use = to assign one. Choose names that explain what the value represents; Python is case-sensitive, so score and Score are different names.

variables.py
name = "Mina"
score = 8
score = score + 1

print(f"{name} has {score} points.")
Mina has 9 points.

The f before a string lets you insert a value inside braces. It's a handy way to build readable messages.

03 — Values have shapes

Meet the basic data types

Different kinds of information support different operations. Here are four types you'll use constantly:

String · strText, wrapped in quotes: "hello"
Integer · intWhole numbers: 42
Float · floatDecimals: 3.14
Boolean · boolTrue or false: True
types.py
temperature = 21.5
is_sunny = True
city = "Oslo"

print(type(temperature))  # <class 'float'>

Convert between types with functions such as int("12"), float("3.5"), and str(42).

04 — Choose a path

Make decisions with if

Use an if statement to run code only when a condition is true. Add elif for another possibility and else for everything that remains.

decisions.py
temperature = 18

if temperature >= 25:
    print("Warm day")
elif temperature >= 15:
    print("Light jacket weather")
else:
    print("Bring a coat")
Light jacket weather

Comparisons include == (equal), != (not equal), >, <, >=, and <=. Combine conditions with and or or.

05 — Repeat a task

Let loops do the repeating

A for loop visits each item in a sequence. range(1, 4) produces 1, 2, 3: the starting number is included, but the ending number isn't.

loops.py
for number in range(1, 4):
    print(f"Count: {number}")
Count: 1
Count: 2
Count: 3

Use a while loop when you want to repeat until a condition changes. Make sure that condition can eventually become false, or the loop will never stop.

06 — Reuse an idea

Bundle steps into functions

A function gives a set of instructions a name. Define one with def, pass information in through parameters, and use return to send a result back.

functions.py
def greet(name):
    return f"Hello, {name}!"

message = greet("Ravi")
print(message)
Hello, Ravi!

Functions are especially useful when you want to repeat an operation or give a complicated task a simple, descriptive name.

07 — Keep things together

Work with lists and dictionaries

A list stores an ordered group of items. A dictionary stores values under named keys. Both can grow as your program runs.

collections.py
fruits = ["pear", "plum"]
fruits.append("peach")
print(fruits[0])  # pear

person = {"name": "Ari", "age": 27}
print(person["name"])  # Ari

List positions start at zero, so fruits[0] is the first item. For a dictionary, look up a value using its key, like person["name"].

08 — Keep learning

Handle errors, one step at a time

Errors are useful clues. When an operation might fail, try and except let your program respond instead of stopping unexpectedly.

errors.py
text = "42"

try:
    number = int(text)
    print(number + 1)
except ValueError:
    print("Please enter a whole number.")
